## 1. 背景与目标

- 内网版（aitoolbox.maihaoche.net）已上线运行，当前为**无账号模式**：游客可上传、点赞连点无上限、无收藏。
- 已确认合规可上公网；公网切换时机 = **账号系统上线时**（禁止无账号裸奔上公网）。
- 本次改造目标：建立账号体系与角色权限，先在内网运行验证，之后原样迁公网。

## 2. 账号体系

| 项 | 定案 |
|---|---|
| 登录方式 | ① 账号密码 ② 企业微信扫码（二期接通，先留占位） |
| 注册 | **不开放自主注册**，账号由管理员分发（后台建号） |
| 密码找回 | 管理员后台重置（无自助找回） |
| 企微接入 | 用现有自建应用：配可信域名 + 可信 IP（无 API，需后台手动配），拿 agentid/secret |

## 3. 权限矩阵（2026-10-23 拍板）

| 操作 | 游客（未登录） | 登录用户 | 管理员 |
|---|---|---|---|
| 浏览 / 搜索工具 | ✅ | ✅ | ✅ |
| 下载附件 | ✅ | ✅ | ✅ |
| 点赞 | ✅ 连赞无上限（同直播点赞，登录与否一致） | ✅ 连赞 | ✅ 连赞 |
| 收藏 | ❌（按钮隐藏 / 点击提示登录） | ✅ | ✅ |
| 上传工具 | ❌（提示登录） | ✅ | ✅ |
| 删除工具 | ❌ | ❌ | ✅ |
| 编辑工具（标题/简介/详情等全部文本） | ❌ | ❌ | ✅ |
| 修改展示数据（上传/下载/收藏计数） | ❌ | ❌ | ✅ |
| 账号管理（建号 / 重置密码 / 禁用） | ❌ | ❌ | ✅ |

角色只做两级：**普通用户 / 管理员**（系统内置一个超管兜底账号，不作为可分配等级）。

## 4. 功能需求

### 4.1 登录 / 会话
- 登录页：账密表单 + 企微扫码占位按钮（标注"暂未开通"）。
- 会话：Cookie + 服务端 Session（hashlib/hmac 标准库实现，禁明文存密码，PBKDF2 加盐哈希）。
- 登录态有效期 7 天；登出即销毁。
- 访客可看全部内容，触发上传/收藏动作时引导登录。

### 4.2 收藏（登录后开放）
- 个人收藏列表（个人主页可见）。
- 数据落库：user↔tool 关系表；每人每工具一次，可取消。
- 游客不显示收藏入口。

### 4.3 上传需登录
- 上传记录挂 `created_by`（上传者），个人主页展示"我上传的工具"。
- 上传后直接上架，**不做审批流**（2026-10-23 拍板：企微实名登录 + 账密内部分发，人不匿名，无需先审后显）；管理员可随时编辑/删除。

### 4.4 管理员能力
- **删除工具**：软删除（进回收站可恢复，防误删；30 天后物理清理）。
- **编辑工具**：可修改全部文本字段（标题、部门、类型、简介、详情、链接）。
- **修改展示数据**：可直接设置某工具的"下载量 / 点赞量 / 收藏量"对外展示数字（用于初始化真实数据、修正异常值）。
  - 建议：修改留痕（谁、何时、从多少改成多少），不计入对外展示。
- **账号管理**：单个建号（姓名+初始密码）+ 批量导入（Excel/CSV 名单）；重置密码；禁用/启用。

### 4.5 个人主页
- 我的信息（姓名、账号、角色）、修改自己密码。
- 我上传的工具、我收藏的工具。

## 5. 数据模型变更（SQLite，兼容现有库）

```
users        (id, username, name, dept, pwd_hash, salt, role[user/admin],
              status[active/disabled], created_at)
sessions     (token, user_id, expires_at)
tools        + created_by 列（老数据为空 = 迁移前导入，兼容）
favorites    (user_id, tool_id, created_at, UNIQUE(user_id,tool_id))
             —— 仅收藏；点赞保持 tools.likes 整数列连点（2026-10-23 拍板，
                类直播连赞，无需关系表、不区分登录态）
tools.downloads 保留计数列（游客匿名下载，无需关系表）
audit_log    (id, admin_user_id, action, target, before, after, created_at)
             —— 记录管理员删改、计数修改（2026-10-23 拍板：留痕）
```

- 兼容策略：老库启动时自动迁移（ALTER TABLE 加列、建新表），现有 6 条工具数据无损。
- 迁移前**必须先备份线上库**：让运维拷贝 `/data/ai-tools/` 目录（容器 stop 状态下拷最稳）。

## 6. 接口变更

新增：`POST /api/login`、`POST /api/logout`、`GET /api/me`、
`POST /api/favorite/{tool_id}`（切换）、`GET /api/my/tools|favorites`、
管理员：`POST /api/admin/users`、`POST /api/admin/users/import`、
`POST /api/admin/users/{id}/reset-pwd|disable`、`PUT /api/tools/{id}`、
`DELETE /api/tools/{id}`（软删）、`POST /api/admin/tools/{id}/counters`。

变更语义：
- `/api/upload`、`POST /api/tools`：未登录返回 401，前端引导登录。
- `GET /api/tools` 列表：游客可见，返回体增加 `favorited`（仅登录时有值）。
- `POST /api/tools/{id}/like`：保持现状（连点、无身份），登录与否一致。

## 7. 安全要点

- 密码：PBKDF2-HMAC-SHA256 ≥10 万次迭代 + 随机盐；会话令牌 `secrets.token_urlsafe`。
- 管理接口全部校验 role；禁用账号即时踢下线。
- 公网上线前置：HTTPS 证书（企微回调硬性要求）、出口 IP 写入企微可信 IP、nginx 层限流。
- 内网阶段无鉴权接口（旧版行为）在账号上线后全部关闭。

## 8. 里程碑

| 阶段 | 内容 | 交付 |
|---|---|---|
| M1 内网账号版 | 登录/个人主页/收藏/上传挂人/管理员四项能力 | 容器包，运维替换部署 |
| M2 公网版 | HTTPS + 企微扫码登录接通 + 域名切公网 | 与 M1 同库同代码，仅配置差异 |

## 9. 已拍板结论（2026-10-23，原待确认项）

1. **上传不做"先审后显"**——企微实名登录 + 账密内部分发，人不匿名，无需审批。
2. **点赞保持连赞**（类直播点赞），无上限、不区分登录态；只有收藏需要用户关系表。
3. **管理员修改展示计数需留痕**（audit_log），管理界面样式由开发设计定。
